# CreatorMind: Your Autonomous AI Growth Manager

Most AI content tools answer one prompt at a time. You give them a prompt, they give you a script, and the interaction ends. They forget who you are the next time you open them.

**CreatorMind is different.** It is a persistent, autonomous creator-growth Mind that learns what works for you, remembers every decision and outcome, continuously identifies opportunities, and proactively follows up—even while you sleep.

## 🚀 The Core Loop is the Product

A normal chatbot: `Prompt → Answer → End`

CreatorMind: 
`Goal → Observe → Reason → Act → Observe Outcome → Learn → Update Memory → Follow Up → Loop`

We didn't just build another AI feature. We built an autonomous loop that mathematically optimizes your channel's growth.

---

## ✨ Key Features

### 🧠 1. Persistent Creator Memory ("What Your Mind Knows")
Your agent maintains a permanent **Creator DNA** profile (your niche, audience, tone, and constraints). As you use the platform, it dynamically extracts **Learned Preferences and Patterns** from your feedback and analytics. It never suggests a generic idea, and it never forgets what you like.

### ⚙️ 2. Autonomous Background Worker
You don't need to click buttons for the AI to work. A continuous background worker polls the database, checking on your goals, monitoring live YouTube metrics, and generating new content opportunities entirely on its own. You can track everything it does in the real-time **Activity Timeline**.

### 🧪 3. The Opportunity Engine & Growth Experiments
When the Mind detects a growth opportunity, it doesn't just guess. It proposes A/B experiments (e.g., *Test A: Standard Hook vs. Test B: Problem-First Hook*). The background worker securely fetches real-time YouTube metrics to observe the experiment outcomes. 

### 💡 4. "Why Did I Do This?" Explainability
AI shouldn't be a black box. Every opportunity generated by CreatorMind includes a transparent "Why Did I Do This?" evidence panel, explicitly listing the historical data, audience comments, and DNA alignment that led the agent to its decision.

### 💳 5. Integrated Monetization
A fully functioning Stripe integration supports Pro/Starter subscriptions, handled securely via Supabase Edge Functions.

## 🛠️ Tech Stack

- **Frontend:** React, TypeScript, Vite, Tailwind CSS, `shadcn/ui`
- **Routing:** React Router
- **Backend/Database:** Supabase (PostgreSQL, Row Level Security)
- **Background Autonomy:** Node.js Worker (`agent-worker.mjs`) interacting with Supabase via `service_role_key`
- **Serverless API:** Supabase Edge Functions (Deno) for Stripe and data syncing
- **AI Intelligence:** Minds SDK integration for persistent memory and reasoning

## 💻 How to Run Locally

### 1. Prerequisites
- Node.js (v18+)
- A Supabase account
- A Stripe account (for billing features)

### 2. Environment Variables
Create a `.env` file in the root directory:
```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key

# Stripe
VITE_STRIPE_STARTER_PRICE_ID=price_...
VITE_STRIPE_PRO_PRICE_ID=price_...
```

*(Note: Edge functions require `STRIPE_SECRET_KEY` to be set in your Supabase project secrets).*

### 3. Install Dependencies
```bash
npm install
```

### 4. Run the Frontend
```bash
npm run dev
```

### 5. Run the Autonomous Background Worker
Open a **second** terminal and run the continuous background loop:
```bash
node scripts/agent-worker.mjs
```
